## Decisions Made

- Snapshot through SQLite's online backup from a `mode=ro` connection rather than `shutil.copy2`: the unattended runner writes the developer database every 15 minutes, so a byte copy can catch a half-written file, and the read-only URI means the notebook cannot write the source even by mistake.
- The guard requires the resolved path's parent directory to start with `fomo-notebook-db-` instead of requiring `/tmp`, so it holds where the temp directory is elsewhere.
- Static inspection uses `ast` so comments cannot satisfy or trip a check.
