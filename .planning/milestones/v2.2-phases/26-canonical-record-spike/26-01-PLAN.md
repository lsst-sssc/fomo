No-shippable-code investigation spike (mirrors Phase 13's and Phase 18's plan 01). The usual
Nyquist "add a test for the new behavior" framing does not apply: this plan changes no shipped
`solsys_code/` behavior, so there is nothing for a permanent unit test to assert against.

output block, a before/after row-count diff, and a before/after fingerprint of the real dev DB.

suite already asserts the exact behaviors the rename must preserve (admin changelist renders,
sidecar create-or-update succeeds, dashed-border class appears), which is strictly better
evidence than a new bespoke script (RESEARCH.md "Don't Hand-Roll").

attempt and segfaulted inside REBOUND/ASSIST on a second (RESEARCH.md Pitfall 3). Use the named
module list in task 3. Narrowing the label does **not** avoid the ~9s SPICE-furnish cost —
`DiscoverRunner.run_tests()` calls `manage.py check` unconditionally, which imports the full
URLconf (RESEARCH.md Pitfall 2). Budget for it; do not try to engineer around it.
