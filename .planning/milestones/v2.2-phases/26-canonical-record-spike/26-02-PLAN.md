coexistence proof, and SPIKE-03's adopt-vs-gap-fill prototype against `CampaignRun` pk=1's real
window. Bracketed by the one step of this phase that has no automated substitute — a human
loading `/calendar/` in a running dev server after the companion-record rename (D-02).

DB on the scratch branch `spike/26-canonical-record-probe`; no reconciler module, no migration
and no UI ships. The only committed artifact is `26-DECISION.md`.

their transactions** — they deliberately do *not* use Phase 18's rolled-back
`transaction.atomic()` pattern, which existed because that spike ran against the live
`Observatory` table. The decision doc must state that difference so a future reader does not
assume rollback is a universal spike convention.

wording with a real executed check, and settle D-11 by measurement rather than in the abstract.
Output: `26-DECISION.md` Findings extended with the manual `/calendar/` result, the verbatim
coexistence PASS/FAIL lines, and the three-way event-count comparison plan 26-03 makes its
recommendation from.
