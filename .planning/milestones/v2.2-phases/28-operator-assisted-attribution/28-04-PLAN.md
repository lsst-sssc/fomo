existing idiom.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> `campaigns:attribution` (GET) | Untrusted session reaching a staff-only page that renders run detail, event titles and free-text dismissal reasons |
| stored data -> rendered HTML | Event titles, `site_raw`, `telescope_instrument` and dismissal reasons are community-sourced or externally-fetched text rendered into the page |
| browser -> `campaigns:list` (GET) | Anonymous visitors reach the campaign list; the staff banner must not render for them |
