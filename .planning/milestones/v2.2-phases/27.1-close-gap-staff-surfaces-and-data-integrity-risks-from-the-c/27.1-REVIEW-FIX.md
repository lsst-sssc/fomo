## Process note

Fixes were made in an isolated git worktree (`gsd-reviewfix/27.1-…`), fast-forwarded onto
`issue37-telescope-runs-calendar`, and the worktree, temp branch and recovery sentinel were all
cleaned up (`git worktree list` shows only the main checkout).

One deliberate deviation: the notebook regeneration (`3d5adc3`) was run in the main working tree

previously fixed WR-06; executing it from the real repo root *before* the merge would have
exercised the *unfixed* importer. Running it after the merge is the only ordering in which both
the code under test and the recorded path are the real ones.
