<objective>
Cut `load_telescope_runs` over from writing `CalendarEvent` rows directly to creating or
updating one `CampaignRun` per observing night and handing calendar projection to
`reconcile_run()`, in the same commit (D-05: hard cutover per adapter, classical first, no
dual-write and no feature flag).

Purpose: ADAPT-01, and the first real consumer of the groundwork helper. Classical is
first because it is the one adapter whose projection is faithful — the reconciler
recomputes the same `sun_event(site, night, kind='sun')` values this command already
computes, so a BoN/EoN night projects to the same times it has today.

Output: a rewired command, no-churn and cutover-simulation tests, a regenerated demo
notebook, and the runbook section describing what the command now writes.
</objective>
