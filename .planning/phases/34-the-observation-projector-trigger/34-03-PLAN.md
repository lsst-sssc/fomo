<objective>
Make the projector's markers and series identity visible: status rings and a legend for the new
compact marker vocabulary, and a "night n of N" decoration in the event modal rendered from the
group link rather than from stored text.

Purpose: the projector writes a marker and a group foreign key; on its own that is invisible. This
plan is the half a user actually sees — and it is deliberately a display-time reading of two links,
so that re-projecting an event can never erase what the calendar shows (the lesson spike 003 paid
for and Phase 33's `campaign_decoration()` already encodes).

Output: an extended `_TERMINAL_PREFIXES` / `status_border_css()`, a marker legend on the calendar
page, a new `observation_series_decoration()` template tag with its modal block, and the calendar
view's prefetch widened so neither addition costs a query per event.
</objective>
