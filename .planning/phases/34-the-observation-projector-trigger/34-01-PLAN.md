<objective>
Build the observation projector and its Django signal trigger: every LCO/SOAR
`ObservationRecord` draws and keeps current exactly one `CalendarEvent`, with no operator
command.

Purpose: this is the mechanism the whole v2.4 base layer rests on. Phase 33 inverted the
reconciler so it will not steal these events and shipped the `CalendarEventMeta` link fields;
this plan is the writer that fills them. Until the receiver exists, a placed block only reaches
the calendar when somebody remembers to run a command.

Output: `solsys_code/observation_projector.py` (stage classifier, marker/title builder, event
field builder, never-raise `project_record()`, meta-link writer, and the three receivers), the
`SolsysCodeConfig.ready()` wiring that connects them, and two new test modules proving the
stage rules and the receiver contracts.
</objective>
