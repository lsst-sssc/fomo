<objective>
Close the two remaining verification gaps: the confirm/erase loop that destroys a human's
attribution audit stamps on every sweep (Gap 1 / CR-04, BLOCKER), and the swallowed `blocked`
signal for a night that is both attributed and contested (Gap 2 / WR-13, PARTIAL) — together
with the three operator-facing findings that ride on the same code path (WR-10, WR-11, WR-12)
and the runbook wording that steers operators straight into the destructive path.

Purpose: 33-08 made the attributed-night skip unconditional, so a superseded `RUN:{pk}:{date}`
event drops out of `active_urls` and `_detach_stale_family_events()` clears its
`run`/`confirmed_by`/`confirmed_at`. Phase 28's queue then re-offers that same event to the same
run at HIGH band (score 0.82, reproduced independently by the verifier), a staff member confirms
the obvious match, and the next sweep erases the stamp again — permanently, with only a
`logger.warning` as a record. That contradicts the phase goal ("the reconciler annotates instead
of owning"), ANNOT-01's literal text, module decision D-17 and `unlink_event_from_run()`'s own
"a human attribution always outranks an automated clear". It is reachable from an interactive
staff surface today and from the unattended cron sweep Phase 36 will schedule, and its trigger
shape — a facility/observation-keyed event attributed to the run — is exactly what Phase 34's
projector begins producing next phase.

**The remedy is already decided — do not re-open it.** 33-UAT.md `## Decisions` (2026-09-09):
*"Option B — human outranks machine. The reconciler sweep detaches only rows with no
`confirmed_by`; a human-confirmed attribution is never cleared by an automated sweep. Leftover
`RUN:{pk}:{date}` duplicates on a night remain Phase 35 SC 5's responsibility. Do not write
`CalendarEventDismissal` rows on automated detach."* The dismissal-row alternative from
33-REVIEW.md CR-04's fix block is rejected; no third option is to be invented.

Output: a detach step that yields to a human confirmation and says so, ownership evaluated
before the night's outcome, a dry run that can preview the one irreversible step, staff actions
that report what actually happened, and paired docs that match.
