## Decisions recorded by this plan

**The repo-wide sweep becomes a test, not a one-off grep.** Criterion 2 asks that "no other
multi-line `{# #}` block survives anywhere in the repo". A grep proves that today; a test
proves it on every run. The sweep is scoped to FOMO's own Django template root
(`src/templates/`), which `src/fomo/settings.py:96` names as the only entry in
`TEMPLATES[0]['DIRS']`. `APP_DIRS=True` is also set, but `solsys_code/` ships no `templates/`
directory (`find . -type d -name templates` returns only `src/templates`, `build/lib/templates`
(a build artifact) and `.claude/gsd-core/templates` (GSD tooling markdown, not Django
templates)). So "anywhere in the repo" and "everything under `src/templates/`" are the same set
today, and the test asserts it found a non-zero number of files so a path typo cannot make it
pass vacuously.

**The pre-existing survey (do not re-derive it):** exactly three multi-line `{# ... #}` blocks
exist in the repo, all in `src/templates/tom_calendar/partials/event_form.html`, at lines 1-16,
94-107, and 110-118. `src/templates/tom_calendar/partials/calendar.html` -- FOMO's other
`tom_calendar` override -- contains no `{#` at all. All three blocks must be converted; only
the first two are unconditionally rendered, but the third (inside `{% if
run.is_publicly_visible %}`) leaks for exactly the run the modal is supposed to showcase.

**Addition C -- the repo-wide sweep.** A new `TemplateCommentSyntaxSweepTest(SimpleTestCase)`
(no database access needed) with one method,
`test_no_multiline_django_comment_blocks_in_fomo_templates`. It resolves the repo root with the
`Path(__file__).resolve().parents[2]` idiom already used at line 500 of this module, walks
`repo_root / 'src' / 'templates'` recursively for `*.html`, and for each file scans every `{#`
occurrence, locating its matching `#}` with `str.find`. It fails if any such span contains a
newline (Django's `{# #}` is single-line only, so a spanning block renders literally), and also
fails if a `{#` has no matching `#}` at all. Include the offending file path and 1-based line
number in the failure message. Before asserting, assert the walk found at least one `.html` file
-- without that guard a path typo would make the test vacuously green. Document in the method
docstring why `src/templates` is the whole search space (settings' `TEMPLATES[0]['DIRS']` names
it and no installed FOMO app ships a `templates/` directory).
