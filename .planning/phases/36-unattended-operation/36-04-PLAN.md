  explicit delegation, not a deferral. It is included because SC 5 is "set up, **or verify**, the
  whole schedule", and without it the only way an operator can verify the mail layer is to wait
  for a real failure. Anyone reading the Deferred list should read this note as the decision that
  closed that item, not as a plan implementing a deferred idea.
- **Lock/log directory checks read only.** `check_unattended` reports that `/var/lock/fomo` and
  `/var/log/fomo` are missing rather than creating them: the two directories usually need an owner
  and mode the Django process is not entitled to choose, and a diagnostic that silently changes
  the host is worse than one that tells the truth.
- **Every check runs even after one fails.** `handle()` collects all results and raises a single
  `CommandError` at the end, so a fresh-host operator sees the whole list of problems in one run
  instead of fixing them one per invocation.
</decisions_this_plan_records>
