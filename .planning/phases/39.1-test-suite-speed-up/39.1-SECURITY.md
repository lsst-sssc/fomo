# Phase 39.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| callers (allocation projector, gap analysis, loaders, views) -> `sun_event()` | callers pass an Observatory and a date; `sun_event()` validates them, then reads the per-process memo | site coordinates, timezone, date; cached astropy `Time` crossings |
| memo -> callers | cached `Time` objects are mutable and are never handed out directly | copies of cached `Time` objects |
| process command line -> settings import | `sys.argv[1] == 'test'` decides whether the test-only overrides (LocMemCache, MD5 hasher) apply | settings values; password hashing strength |
| test processes <-> shared temp directory | the FileBasedCache and the coverage data files live in shared directories | cache entries, `.coverage.*` data files |
| package registry -> dev venv / CI | a new dev dependency (tblib) is installed from PyPI | third-party code |
| developer machine hook -> CI | tests the hook skips (`migration` tag) must still run in CI | test coverage assurance |
| local repository -> public GitHub PR branch | a push publishes code and is costly to undo | source tree minus `.planning/` |
| primary checkout <-> worktree | branch-implicit git commands can hit the wrong checkout | branch state |
