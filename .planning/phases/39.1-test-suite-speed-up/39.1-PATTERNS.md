**Current `_find_crossing`** (lines 199-240) to replace. Keep the signature: keyword names `anchor, location, threshold_deg, search_hours=24` and a `coarse_step_min` kwarg (default changes 1.0 -> 10.0); return `list[Time]`; the test calls `_find_crossing(anchor, location, threshold_deg=-18.0, search_hours=24)`. The old loop being replaced:
```python
    offsets = np.arange(0, search_hours * 60 + coarse_step_min, coarse_step_min) * u.min
    times = anchor + offsets
    alt = _solar_altitude(times, location)
    crossings = []
    for i in range(len(alt) - 1):
        if (alt[i] - threshold_deg) * (alt[i + 1] - threshold_deg) < 0:
            lo, hi = times[i], times[i + 1]
            lo_alt = alt[i]
            for _ in range(10):
                mid = lo + (hi - lo) / 2
                mid_alt = _solar_altitude(Time([mid]), location)[0]
                if (mid_alt - threshold_deg) * (lo_alt - threshold_deg) < 0:
                    hi = mid
                else:
                    lo, lo_alt = mid, mid_alt
            crossings.append(lo)
    return crossings
```
Target: the "Coarse scan plus vectorised bisection" excerpt in 39.1-RESEARCH.md (145 samples, 14 vectorised bisection steps, returns lower bracket end). Keep the existing Google docstring (Args/Returns) and update the "coarse scan" wording; add a code comment recording the accepted limitation (a double crossing inside one 10-minute step can be missed; `sun_event()` raises on count != 2).

**`sun_event` validation order to preserve** (lines 280-306): timezone check -> `location = site.to_earth_location()` -> `anchor = _local_noon_utc(...)` -> threshold selection (`'sun'`: `-(0.833 + dip.to_value(u.deg))`, `'dark'`: `-15.0`, else `ValueError`) -> crossings -> `len(crossings) != 2` check raising the error that names `site.short_name`, `date`, `kind`. Only the line
```python
    crossings = _find_crossing(anchor, location, threshold, search_hours=24)
```
changes, to `[t.copy() for t in _cached_crossings(site.lon, site.lat, site.altitude, site.timezone, date, threshold)]`. The `anchor`/`location` locals in `sun_event` are then used only for validation side effects; ruff F841 may flag an unused `anchor`, so drop it or keep `location = site.to_earth_location()` as a bare call (no assignment). Place `_cached_crossings` (with `@lru_cache(maxsize=4096)`) between `_local_noon_utc` (line 243) and `sun_event` (line 258) so `_local_noon_utc` is defined above it (not required at runtime, but reads in order).
