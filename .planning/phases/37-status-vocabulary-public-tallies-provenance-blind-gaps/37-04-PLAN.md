<objective>
Build the one module every public tally surface reads: per-run counts, per-run night counts by
state, the shared unused-night classifier, and the campaign roll-up (TALLY-01, TALLY-02,
TALLY-03, UNUSED-01).

Purpose: D-08 forbids a per-row query loop and D-15 requires the table and the calendar to agree
by construction. Both are only achievable if the counting lives in one place, with the
SQL-expressible counts done in one annotated query and the site-local-night counts behind the
same low-level TTL cache `campaign_gap.py` already uses. The display surfaces (37-05, 37-06)
then render values rather than compute them.

Output: `solsys_code/campaign_tally.py` and its test module, including the TALLY-03 guard.

**Paired docs:** owned by plan 37-07 (wave 5).
</objective>
