<objective>
Execute CANON-05 and the visible-surface half of CANON-01: make the two new links visible and
editable to staff, make an event reach its run from the calendar modal, and put each new field on
exactly the surface its decision says it belongs on.

Purpose: without an editable admin inline, nothing in Phase 27 can create an observation link at all
— Phase 28's real staff attribution UI is where a link normally gets made, and it has not shipped
yet (D-06). But an editable inline is also a write path that bypasses the confirmation flow, so
D-07 requires `save_formset` to stamp the acting user and time; without it the audit trail D-03
designs has holes on precisely the rows this phase creates. D-18 puts `telescope_class` on the
public run table and deliberately withholds `source`, which is internal ingest provenance whose
`LEGACY` value would read as meaningless to an outside reader.

Output: two admin inlines with attribution stamping, two new admin filters, one upstream-template
override, one new field on the non-staff allow-list, `source=WEB` on the submission path, and tests
for all of it.

**Two patterns here have no in-house precedent.** `grep -rn "Inline" solsys_code/` and
`grep -rn "save_formset\|save_model" solsys_code/` both return zero matches (27-PATTERNS.md
`## No Analog Found`). Django's own stock idiom is the only reference — follow 27-RESEARCH.md's
Code Examples section, which was verified against the installed
`django.contrib.admin.ModelAdmin.save_formset` source, and do not invent a house style for it.
</objective>
