<objective>
Finish CANON-01 and CANON-02 on the ingest side, and ship the paired documentation that CLAUDE.md
treats as part of the deliverable rather than as follow-up polish.

Purpose: `import_campaign_csv` is one of D-20's two required call sites for the shared derivation
helper — without it, a newly imported class-wide run would carry a blank `telescope_class` while an
existing one carried a derived value, and the field would rot the moment the backfill landed. It is
also the only existing code path that creates `CampaignRun` rows outside the web form, so it is where
`source=CSV_IMPORT` belongs.

The paired docs are in `files_modified` from the start because CANON-01 and D-20 genuinely change what
this command writes, which is CLAUDE.md's stated trigger. This rule has recorded breach history
(Phase 5 `260619-f7u`, Phase 6 `260620-v9x`, and quick task `260726-kdp` where the operator runbook
went stale) — the notebook and the runbook are tasks here, not a follow-up.

Output: the importer's two new writes with tests, the regenerated pre-executed notebook, the updated
operator runbook, and the three planning-doc corrections this phase folded in.
