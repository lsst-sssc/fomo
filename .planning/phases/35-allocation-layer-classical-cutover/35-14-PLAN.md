<objective>
Close WR-02, a regression this phase's own first gap-closure round introduced. NF-21 added a
per-line `except ZoneInfoNotFoundError` handler that increments `run_skipped`, but the dry-run
branch had already folded the line into `run_created` / `run_updated` / `run_unchanged` before
reaching the `reconcile_run(existing, dry_run=True)` call that can raise. One line therefore
lands in two counters on the preview and one counter on the real pass, so the preview's totals
no longer sum to `lines processed` and an operator reading the dry run believes a run will be
left untouched when the line will in fact be dropped.

The real branch does not have this shape: it increments only after its `transaction.atomic()`
block has returned. The fix is to mirror it.

Purpose: a preview exists so an operator can trust it. The whole value of "always run
`--dry-run` first" -- which this project's runbook tells operators in seven places -- depends on
the preview reporting the same decision the real pass will report.

Output: a re-ordered dry-run branch; a dry/real parity assertion added to the regression class
NF-21 created; and the paired demo notebook extended with an executed dry/real parity cell.

Wave 1, no dependencies. No file overlap with plans 35-12 or 35-13. Plan 35-15 depends on this
one for the runbook sentence describing the restored invariant.
</objective>
