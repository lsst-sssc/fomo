<objective>
Bring the existing test suite across to the `ALLOC:` namespace. Plan 35-01 deleted the
`RUN:{pk}:{date}` per-night writer and changed which family a queue-sourced run belongs to; roughly
ninety assertions across seven test modules still describe the old world. This plan migrates them
with an explicit classification table, so nothing is silently dropped and the suite is green again
before any later wave builds on it.

This plan is an expansion slice of the tracer proven in 35-01 — it refines the same capability
(every run reaches the right key family) by making the suite state the new contract, and it adds no
production behaviour of its own.

Purpose: ALLOC-01 and ALLOC-03 are only real once the suite asserts them; a green label-list run is
the gate every later wave depends on.

Output: seven migrated test modules and a classification table in the plan summary.

Paired docs for this phase are owned by plan 35-07 (wave 5). This plan changes no documented
operator behaviour.
</objective>
