**How this plan carries out D-G5 (2) so that its claim -- "covers aliases and automagic" -- is true (planning-time
findings, reproduced with IPython 9.10.1, automagic on, autocall 0):**
- A one-line cell that is valid Python can still be run by IPython as an alias or magic: `rm -r -- '../../src'` parses
  as a chain of subtractions, yet `transform_cell` turns it into `run_line_magic('rm', "-r -- '../../src'")`, and on
  dummy files `run_cell("rm -r -- '../src'")` deleted the directory. The same holds for `rehashx`, `store -r`,
  `reset -f`, `time -x` and `sx('rm' ' -r' ' x')`. IPython applies these dynamic transforms only to a cell that is one
  line after its static transforms (InteractiveShell.transform_cell), and only when the first word is a line magic
  or alias not shadowed by a user name, a builtin or a keyword (AutoMagicChecker) and not followed by `=` or `,`
  (AssignmentChecker). So the allow-list gains an **automagic rule** built from IPython's own pieces:
  IPython.core.splitinput.split_user_input for the first word, and a line-magic name set built from IPython itself.
- `In [1]: rm -r -- '../../src'` is also valid Python (an annotated assignment), but IPython's static prompt stripper
  removes `In [1]: ` and then runs the alias. So "leaves parseable Python" is checked together with "and IPython's
  own static transformer (TransformerManager) leaves it unchanged in meaning". TransformerManager leaves every code
  cell of the eight real notebooks unchanged (planning-time check).
- **Harmless magic lines (the set the verifier named, adjusted with reasons):** `%matplotlib inline` (only the
  `inline` argument: another backend such as `module://name` imports a module by name), and a first-line `%%time`
  (IPython refuses a statement after it) or `%%capture` with only its `--no-stderr`, `--no-stdout`, `--no-display`
  flags and an output name. **`%config` is not harmless:** `%config AliasManager.user_aliases = [...]` defines a
  shell alias that a later one-line cell runs, and `%config` reconfigures other magics. Cell magics count only on the
  first line, where IPython honours them. The code left under a harmless magic is checked by every later rule.
