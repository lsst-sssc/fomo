<objective>
Close UAT gaps G-37.1-1-allocurl and G-37.1-1-pager, two display defects the user hit while
checking the July 2026 calendar and the attribution page.

Purpose: the allocation layer stores its namespace key (`ALLOC:{run.pk}:{night}`) in
`CalendarEvent.url`, and the campaign reconciler stores `RUN:{pk}` there too; the event pop-up form
renders ANY non-empty url as a "View" link, so staff saw `ALLOC:1:2026-07-07` as an obviously broken
link. Separately, both attribution tables set no `template_name`, so django-tables2 3.0.0 renders
them with its plain default template, whose pager is an unstyled list ("12next").

Output: an `is_web_url` filter and an event-form label that links only web addresses (which also
stops a stored `javascript:` url ever becoming a link); both attribution tables on Django-tables2's
Bootstrap 5 responsive template; render and guard tests. No paired doc is triggered:
`calendar_display_extras.py` and `campaign_tables.py` are not in CLAUDE.md's notebook map, and no
page under `docs/runbooks/` describes the URL field's link or the attribution tables' pager
(checked at plan time with a grep of `docs/runbooks/telescope_runs_calendar.rst`).
</objective>
