### `solsys_code/campaign_system_links.py` (service, pure read then single write)

**Analog:** `solsys_code/campaign_attribution.py`

**Window helper to reuse, do not reimplement** (lines ~665-681):
```python
def _record_window(record: ObservationRecord) -> tuple[date_cls | None, date_cls | None]:
    try:
        start, end = record_time_window(record)
    except (KeyError, ValueError):
        return None, None
    return start.date(), end.date()
```
Catches only `KeyError`/`ValueError`; a `parameters=None` record raises `TypeError`, so wrap `find_exact_run` in a broad `except Exception` inside `attempt_system_link` (log class name only, see RESEARCH Pitfall 3).

**Campaign-membership idea** (reuse the idea, not the function, because it admits `PENDING_REVIEW`): `CampaignRun.objects.filter(campaign__in=record.target.targetlist_set.all())` in `_eligible_runs_for_record()` (~:582).

**Core skeleton** (RESEARCH Patterns 1-2; module uses single quotes, Google docstrings, `logger = logging.getLogger(__name__)`, must not import `solsys_code.views` or `ephem_utils`):
```python
class SystemLinkMatch(NamedTuple):
    run: CampaignRun
    basis: str

candidates = list(CampaignRun.objects.filter(
    approval_status=CampaignRun.ApprovalStatus.APPROVED,
    proposal_code=proposal, window_start__lte=start, window_end__gte=end))
# step 1: exactly one with r.target_id == record.target_id -> BASIS_TARGET (2+ -> None, no fallthrough)
# step 2 (only if none carry target): unique approved, windowed same-proposal run across
#   record.target.targetlist_set campaigns (judge uniqueness BEFORE window filter -- RESEARCH Open Question 1, needs user decision)
# last: ObservationRecordDismissal.filter(observation_record_id=record.pk, run_id=winner.pk).exists() -> None
```
Guards: empty trimmed proposal returns `None` (live DB has 32 blank-code runs); `record.pk is None` skips the existing-link and dismissal queries so dry-run can ask about an unsaved record.

**Entry point shape** (outcomes `linked / would_link / none / skipped`): dry-run writes only the "Would system-link ..." stdout line; real path calls `create_system_link`, stderr line with `type(exc).__name__` only on failure (D-17 convention in `sweep_watched_rows()`); `created=False` from the write counts as no link. Identifiers formatted with `!r`.

## Shared Patterns

### Own savepoint around any write that may raise `IntegrityError`
**Source:** `solsys_code/campaign_views.py` `_do_confirm_record` (~:1409-1428), also `_dismiss`, `_undo_confirmation`
**Apply to:** `create_system_link`, so a caught error cannot poison the sweep or a test transaction.

### Human outranks machine; confirmation is a row's existence
**Source:** `get_or_create(observation_record=..., defaults=...)` + `unique_campaign_run_observation_record` (`solsys_code/models.py` ~:636-639)
**Apply to:** the writer; `confirmed_by=None` is the only provenance (no flag, no field, no migration).

### Dry run reads only (T-kpy-01)
**Source:** `sweep_proposal()` dry-run branch in `backfill_lco_observations.py`
**Apply to:** both commands; would-link line printed, no `get_or_create`.

### One definition per count (D-10)
**Source:** `campaign_attribution.orphans_needing_attribution_count()` / `unattributable_orphan_count()` docstrings
**Apply to:** all banner/page/queue counts; no inline `.count()`.

### Logging / error text
**Source:** `sweep_watched_rows()` D-17 convention: class name only, `!r` for identifiers. Module logger `logger = logging.getLogger(__name__)`.

### Code style
Single quotes, 120 cols, Google docstrings, plain English in docstrings ("model", not "shape"; "find-or-create", not "upsert"). Gate: `pre-commit run ruff --all-files` and `ruff-format`. Tests via `python manage.py test solsys_code --exclude-tag=ephemeris_segfault`.
