# Phase 37.1: Close gap ALLOC-06 -- exact-identity system links on ingest -- Verification Report

**Phase Goal:** A newly ingested observation record that matches exactly one approved run -- same proposal code, same target (or, when that proposal code belongs to exactly one run in the campaign the target is a member of, campaign membership) and a window inside the run's -- is linked to that run automatically as a system link, so its allocation night retires with no staff action. Anything partial or ambiguous stays in the attribution queue for a person, exactly as today.
