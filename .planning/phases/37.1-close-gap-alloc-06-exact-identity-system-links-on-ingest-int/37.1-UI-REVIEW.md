## Detailed Findings

### Pillar 1: Copywriting (4/4)

**Evidence:** All copywriting is specific and purpose-driven, with no generic fallback patterns.

- **"System (exact match)" label** (models.py:611, campaign_tables.py:699-708): The model defines `SYSTEM_LINK_LABEL = 'System (exact match)'` as a class constant, and `confirmed_by_label()` returns it only when `confirmed_by is None`. This is rendered in the Confirmed table's "Confirmed by" column, making system links immediately distinguishable from staff confirmations. No generic placeholder or empty-string fallback.

- **Kind-aware undo prompts** (campaign_tables.py:551-555): Observation-record dismissal undo prompt warns that "the next discovery sweep or backfill run will link it to that run automatically," while event-dismissal prompt uses unchanged text. The two prompts are dispatched based on record type in `render_actions()` (lines 618-649, 629-630). This guides staff correctly on expected behavior after undo.

- **"not a web link" note** (event_form.html:62): When `form.url.value` is not a web address (e.g., `ALLOC:1:2026-07-07`), the template renders `<small class="text-muted">(not a web link)</small>` and never renders a link. Users know immediately why the URL field does not have a "View" link.

- **Empty-state text consistency**: Attribution page carries distinct, descriptive empty states:
  - "No calendar events awaiting attribution" (attribution_queue.html:143-145)
  - "No observation records awaiting attribution" (attribution_queue.html:229-231)
  - "No confirmed attributions yet" (campaign_tables.py:675)
  - "No dismissals recorded yet" (campaign_tables.py:584)
  Each conveys purpose without placeholder generic text.

### Pillar 2: Visuals (4/4)

**Evidence:** Visual hierarchy is clear through Bootstrap 5 semantics, section state is unambiguous.

- **Confirmed section open by default** (attribution_queue.html:261-270): The Confirmed section carries `class="collapse show"` on load (line 268), making system links and their Undo buttons immediately visible. The trigger button carries `aria-expanded="true"` (line 263). Staff do not need to click to see the system-linked rows 37.1 created.

- **Dismissed section state persists during paging** (attribution_queue.html:250-259): The section is closed by default (`collapsed` class, line 250) but opens when the request carries a page or sort parameter for this table's own fields (lines 250, 257). When a staff user pages through dismissed pairs, the section stays open instead of re-folding, keeping the context visible.

- **Bootstrap 5 collapse attributes** (attribution_queue.html:250-252, 262-263): All section triggers use `data-bs-toggle="collapse"` and `data-bs-target="#id"` — proper Bootstrap 5 syntax, not Bootstrap 4's `data-toggle`/`data-target` spelling. The base template (tom_common/base.html) loads Bootstrap 5, so collapse works as intended.

- **Visual focus on actionable rows**: Confirmed and Dismissed tables carry `table-sm` class for density (campaign_tables.py:674, 583), and the Undo buttons are compact (`btn-sm btn-outline-secondary`; campaign_tables.py:640, 736). The layout does not distract with visual noise.

- **Form layout consistency**: The event-form URL label (event_form.html:54-64) groups the label and optional "View" link in a `<small>` tag, alongside the form field. Staff see the link state and the stored value together without layout shift.

### Pillar 3: Color (4/4)

**Evidence:** All color is applied through Bootstrap semantic classes; no hardcoded hex values or non-standard palettes in the UI layer.

- **Button styling uses semantic classes only**:

  - `btn-primary` for "Confirm selected" (attribution_queue.html:138)
  - `btn-success`, `btn-danger` for per-candidate Confirm/Dismiss (attribution_queue.html:114, 117)

  - `badge text-bg-warning` for Medium
  - `badge text-bg-secondary` for Low

  - `text-center` and `text-truncate` for layout (attribution_queue.html:142; campaign_tables.py:54)
  All standard Bootstrap utilities; no hardcoded `#` values or rgb() anywhere in the six changed files.

- **Section backgrounds**: The "Done" and empty-state boxes use `bg-light` (attribution_queue.html:26, 142, 228), consistent with the page's low-contrast informational style.

### Pillar 4: Typography (4/4)

- **Heading hierarchy**:

  - `<h5 class="font-weight-bold">` for section headings (attribution_queue.html:42, 148, 249, 261)

- **Font-weight usage**:

- **Font-size utilities**:
  - `small` class for explanatory text and labels (attribution_queue.html:43, 53, 56, 85, 88, 89, 150)
  - Default (16px) for form inputs and table cells
  - No custom `font-size` CSS; all sizing through Bootstrap's `small` or implicit defaults.

- **Table and label styling**: Form labels in event_form.html (line 55) use no custom styling; buttons use only `btn`, `btn-sm`, `btn-link` classes from Bootstrap.

### Pillar 5: Spacing (4/4)

**Evidence:** All spacing is applied through Bootstrap utility classes from the standard scale; no `[...]px]` or `[...]rem]` arbitrary values.

- **Margin and padding utilities**:
  - `mb-4` (margin-bottom 1.5rem) on major sections (attribution_queue.html:6, 16, 40, 146, 232)
  - `mb-3` on subsection headings (attribution_queue.html:42, 148, 249, 261)
  - `mb-2` on smaller text (attribution_queue.html:27, 143, etc.)
  - `mt-4` before the Dismissed/Confirmed headings (attribution_queue.html:249, 261)
  - `mr-2` on filter label (attribution_queue.html:9)
  - `me-2` on Attribution button (campaign_list.html:10)
  - `p-4` on empty-state containers (attribution_queue.html:26, 142, 228)

- **Gap spacing for flexbox**:
  - `gap: 0.5rem;` on per-candidate action forms (attribution_queue.html:108, 198) — inline style for custom gap, but tied to a specific layout constraint (flex row of button + input + button), not arbitrary decoration. This is a narrowly justified exception, not a pattern.

- **Column/row layout spacing**:
  - `min-width: 0;` on form cols (event_form.html:41, 44) — CSS for form layout, not a spacing value; this is necessary for flex containers to respect min-width in child inputs.

- **Class-based spacing only**: No hardcoded `margin: 10px` or `padding: 20px` anywhere; all spacing derives from Bootstrap's `m*`, `p*`, `gap` scale classes.

- **Table spacing**: Both AttributionDismissedTable and AttributionConfirmedTable use `class="table table-sm"` (campaign_tables.py:674, 583), which applies Bootstrap's compact row/cell spacing (no custom `td { padding: ... }`).

### Pillar 6: Experience Design (4/4)

**Evidence:** State management is clear, accessibility is built in, user feedback is immediate.

- **Confirmed section visible by default** (attribution_queue.html:268): The section carries the `show` class on load, and the trigger carries `aria-expanded="true"`. System-linked rows are not hidden behind a click; staff can immediately see the "System (exact match)" rows. This directly addresses the UAT gap (G-37.1-1) where the sections never opened under Bootstrap 4.

- **Dismissed section state persistence during paging** (attribution_queue.html:250-257):
  ```django
  {% if dismissed_table.prefixed_page_field in request.GET or dismissed_table.prefixed_order_by_field in request.GET %}
  ```
  The section opens if a page or sort parameter is present; it stays open while staff navigate through dismissals. This prevents the section from collapsing on every page request.

- **Accessibility attributes throughout**:
  - `aria-expanded="true/false"` on collapse triggers (attribution_queue.html:252, 263)
  - `aria-controls="attribution-confirmed-section"` (attribution_queue.html:264)
  - `aria-controls="attribution-dismissed-section"` (attribution_queue.html:253)
  - `for="{{ form.url.id_for_label }}"` on form labels (event_form.html:55, 68)
  Screen readers and keyboard navigation are supported.

- **URL validation prevents malicious links** (calendar_display_extras.py:52-74):
  ```python
  def is_web_url(value: Any) -> bool:
      if not isinstance(value, str):
          return False
      try:
          parts = urlsplit(value.strip())
          return parts.scheme.lower() in ('http', 'https') and bool(parts.hostname)
      except ValueError:
          return False
  ```
  The filter rejects any URL that is not a string with http(s) scheme and a hostname. An `ALLOC:` namespace key, `RUN:` key, or `javascript:` payload never becomes a link (event_form.html:57-62). This closes UAT gap G-37.1-1-allocurl.

- **Kind-aware undo prompts** (campaign_tables.py:551-555, 629-630):
  - Record dismissal: "Undo this dismissal? It will return to the worklist above, or, if it exactly matches one approved run, the next discovery sweep or backfill run will link it to that run automatically."
  - Event dismissal: "Undo this dismissal? It will return to the worklist above."
  Staff receive appropriate guidance before they undo; the behavior difference is explained.

- **Bootstrap 5 table pagination** (campaign_tables.py:678, 587):
  ```python
  template_name = 'django_tables2/bootstrap5-responsive.html'
  ```
  Both attribution tables use Bootstrap 5's responsive template, which renders `<ul class="pagination ..."><li class="page-item"><a class="page-link" ...>`. The pager uses standard Bootstrap styling instead of the unstyled default (UAT gap G-37.1-1-pager).

- **Staff-only access gate** (campaign_list.html:8-11):
  ```django
  {% if request.user.is_staff %}
  <a class="btn btn-outline-secondary me-2" href="{% url 'campaigns:attribution' %}">Attribution</a>
  {% endif %}
  ```
  The Attribution button is visible only to staff, so anonymous visitors cannot navigate to the attribution page. The button is always shown to staff (not gated by attribution_count), addressing UAT gap G-37.1-1-nav: staff can reach the page even when the queue is empty.
