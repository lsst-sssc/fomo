## Directory Purposes

- **Generated by:** `/gsd-map-codebase` skill

  - `ARCHITECTURE.md` — System design, layers, data flow, entry points
  - `STRUCTURE.md` — Directory layout, file purposes, naming conventions
  - `TESTING.md` — Test framework, patterns, coverage strategy

**`solsys_code/`:**
- **Purpose:** Main Django app containing all FOMO business logic
- **Contains:** Models, views, forms, utilities, management commands, tests
- **Key files:**
  - `models.py` — CampaignRun, CalendarEventMeta, CalendarEventDismissal, ObservationRecordDismissal, CampaignRunObservation
  - `views.py` — Ephemeris view, calendar rendering (DO NOT import ephem_utils at module level; defer to view)

  - `campaign_reconciler.py` — Idempotent run→event projection (SINGLE source of truth)
  - `telescope_runs.py` — Classical-run parsing, sun-event calculation
  - `calendar_utils.py` — CalendarEvent adapter, site-telescope mapping

**`solsys_code/management/commands/`:**

## Naming Conventions

**Files:**

- **Python modules:** `snake_case` (e.g., `campaign_reconciler.py`, `ephem_utils.py`)
- **Migrations:** `0001_initial.py`, `0002_add_approval_status.py` (auto-generated by Django)
- **Templates:** `snake_case.html` (e.g., `ephem_form.html`, `campaignrun_table.html`)
- **Test files:** `test_*.py` (e.g., `test_models.py`, `test_campaign_views.py`)

**Directories:**

- **Django apps:** `snake_case` (e.g., `solsys_code`, `solsys_code_observatory`)
- **App sub-packages:** `snake_case` (e.g., `management/commands`, `templatetags`)
- **Template directories:** `snake_case` app-name or feature-name (e.g., `campaigns/`, `tom_calendar/`)
- **Test directories:** `tests/` (Django convention, no module prefix)

**Python Naming:**

- **Classes:** `PascalCase` (e.g., `CampaignRun`, `MakeEphemerisView`, `CalendarEventMeta`)
- **Functions:** `snake_case` (e.g., `reconcile_run()`, `insert_or_create_calendar_event()`, `sun_event()`)
- **Methods:** `snake_case` with Django conventions (e.g., `form_valid()`, `get_queryset()`)
- **Variables:** `snake_case` (e.g., `run_pk`, `site_code`, `event_start`)
- **Constants:** `UPPER_CASE` (e.g., `SITE_TELESCOPE_MAP`, `NO_CAMPAIGN_LABEL`, `RUN_URL_NAMESPACE`)
- **Private/Internal:** Leading underscore (e.g., `_translate_constraints()`, `_FAILURE_PREFIX_BY_STATUS`)
- **Type Hints:** Modern Python 3.10+ style (e.g., `tuple[float, float]`, `dict[str, Any]`, `Optional[str]` or `str | None`)

## Where to Add New Code

### New Feature (e.g., new calendar event type)

**Implementation:**
- Logic module: `solsys_code/campaign_<feature>.py` (pure-logic utility or orchestrator)
- View: `solsys_code/campaign_views.py` (or new `campaign_<feature>_views.py` if substantial)
- Model: Add field/method to existing model in `solsys_code/models.py` or create new model
- Tests: `solsys_code/tests/test_campaign_<feature>.py` (follow existing pattern: Django TestCase)

**URL routing:** Register in `solsys_code/campaign_urls.py`

**Database:** Create migration via `python manage.py makemigrations solsys_code`

**Example (Phase 34 observation-projector integration):**
- Module: `solsys_code/observation_projector.py` (new)
- View: New view method in `solsys_code/campaign_views.py` (ObservationProjectorQueueView)
- Tests: `solsys_code/tests/test_observation_projector.py`
- Migration: `0018_add_observation_projector_fields.py` (auto-generated)

### New Management Command

**Location:** `solsys_code/management/commands/<command_name>.py`

**Template:**
```python
from django.core.management.base import BaseCommand, CommandParser

class Command(BaseCommand):
    help = 'One-line description'
    
    def add_arguments(self, parser: CommandParser) -> None:
        parser.add_argument('--dry-run', action='store_true', help='...')
    
    def handle(self, *args, **options):
        # Implementation
        self.stdout.write(self.style.SUCCESS('Done'))
```

**Pattern:** 
- Use `--dry-run` flag for operations that modify state
- Print summary counters to stdout
- Log details to `logger.debug()` / `logger.info()` / `logger.error()`
- Raise `CommandError` for fatal failures

**Example:** `solsys_code/management/commands/sync_lco_observation_calendar.py` (180 lines)

### New Test

**Location:** `solsys_code/tests/test_<module>.py`

**Framework:** Django `TestCase` (NOT pytest)

**Pattern:**
```python

class TestCampaignRunLogic(TestCase):
    @classmethod
    def setUpClass(cls):
        # One-time setup
        pass
```

### New Model

**Location:** `solsys_code/models.py` (or sub-app if isolated)

**Pattern:**
- Foreign keys: Use `on_delete=models.PROTECT` for referential integrity (unless CANONICAL requires SET_NULL)
- Constraints: Use Meta.constraints for UniqueConstraint / CheckConstraint (no raw SQL)
- Methods: Property for computed values, method for stateless operations
- __str__: Discriminating label for admin + autocomplete (avoid PII)

## Import Patterns

**Avoid circular imports:**
- `solsys_code/views.py` — DO NOT import `ephem_utils.py` at module level (defer to view method)
- `solsys_code/campaign_*` modules — MUST NOT import `views.py` (keeps module-level load fast)
- `solsys_code/ephem_utils.py` — Isolated for ephemeris; imported only by views

**Absolute imports (preferred):**
```python
from solsys_code.models import CampaignRun
from solsys_code.campaign_utils import resolve_site
from tom_calendar.models import CalendarEvent
```

**Relative imports (within app):**
```python
from .models import CampaignRun
from .campaign_utils import resolve_site
```

**No path aliases defined:** This project does NOT use `sys.path` manipulation or `importlib` tricks

## Database Schema Key

**Primary Models:**

- **CampaignRun** — observing run; approval/run status independent; source-tagged; site optional (class-wide)
- **CalendarEventMeta** — companion to TOM CalendarEvent; carries telescope-label verification + run attribution + obs links
- **Observatory** — MPC site; geodetic coordinates; conversion methods

**Relationships:**

- CampaignRun → TargetList (campaign) — nullable (queue/classical runs may have no campaign)
- CampaignRun → Target (observed_target) — nullable (abstract/placeholder runs)
- CampaignRun → Observatory (site) — nullable (class-wide or unresolved)
- CalendarEventMeta → CalendarEvent (event) — one-to-one, CASCADE
- CalendarEventMeta → CampaignRun (run) — nullable (unattributed events)
- CalendarEventMeta → ObservationRecord (observation_record) — nullable, one-to-one, SET_NULL
- CalendarEventMeta → ObservationGroup (observation_group) — nullable, SET_NULL

**Unique Constraints:**

- `(campaign, telescope_instrument, window_start, window_end)` — resolved-window natural key
- `(campaign, telescope_instrument, contact_person)` — TBD (window_start/end NULL) natural key
- `(source_identifier,)` — adapter-sourced rows (non-web sources)

**Check Constraints:**

- `window_start` and `window_end` must be either both NULL or both non-NULL (no partial dates)
